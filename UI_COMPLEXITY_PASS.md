# F.S.A. UI Complexity Pass

This pass upgrades the Fish Shooter Arcade web/PWA without merging it into EGM4000.

## Added
- persistent Reef Ops navigation rail
- live Dragon King event hero and countdown
- quick-deploy mode launchers
- daily mission progress UI
- player XP/resource HUD
- telemetry-link status for the owned F.S.A. simulation
- richer Reef Run combat HUD with sonar, target-value legend, rival seats, boss threat and loadout controls
- boss intel, cannon systems, achievements and local rankings
- dedicated F.S.A. SVG artwork for boss event, gameplay HUD and neon arcade lobby
- PWA cache expansion for the new UI assets
- validation workflow for the complexity pass

## Product boundaries
F.S.A. remains a separate owned virtual/non-cash arcade product. EGM4000 may consume exact telemetry generated by this owned simulation for controlled validation. No third-party game state, credentials, balances, or protections are modified.
