# Deploy F.S.A.

## GitHub Pages
1. Keep the release on `main`.
2. In repository **Settings → Pages**, choose **GitHub Actions**.
3. Open the Pages URL after the workflow finishes.
4. Test New Session, Pause, End Session, cannon levels, experiment sliders, telemetry export, installability, and mobile layout.

## Production boundary
This repository is a standalone static PWA. It intentionally uses browser-local state. The broader SmartPickShop production backend belongs to the shared ecosystem deployment, not this F.S.A.-only repository.

## Real-money boundary
Do not market this release as a real-money casino, deposit/withdrawal product, or cash-prize game. Current credits are virtual/non-cash.
