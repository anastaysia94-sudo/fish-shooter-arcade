# F.S.A. UI Architecture v4

The Fish Shooter Arcade interface is organized as a layered arcade operations shell:

1. **Topbar** — brand, primary navigation, player level/XP, virtual-credit wallet.
2. **Reef Ops rail** — persistent access to play, games, loadout, boss intel, missions, achievements, rankings and slots.
3. **Live Event hero** — rotating owned-game event presentation with countdown and direct table entry.
4. **Quick Deploy** — one-tap entry into representative game modes.
5. **Mission and telemetry panels** — local progression plus exact owned-simulation telemetry status.
6. **Combat preview and Loadout Bay** — communicates the richer Reef Run cockpit and cannon systems.
7. **Game library** — all 15 fish shooters retain room selection and existing gameplay engine behavior.
8. **Progression** — achievements and session-local ranking presentation.
9. **Side arcade** — 20 original virtual-credit reel games remain separate from real-money wagering.
10. **Responsive combat modal** — canvas play area, sonar, target legend, rival seats, score/credit/boss HUD, cannon controls and session metrics.

The visual system uses dark gunmetal/navy panels, cyan/teal signals, copper/orange hardware, gold progression accents and selective violet energy. The shell is responsive from desktop to Android-sized screens.
