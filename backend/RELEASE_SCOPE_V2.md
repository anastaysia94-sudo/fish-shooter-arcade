# Release Scope — Hierarchy v2

This release completes the previously unstarted production hierarchy item:

**Founder → Distributor → Agent → User**

Included: Distributor accounts/permissions/ceilings/game access, mandatory Agent parentage, inherited Agent/User permissions, server-scoped provisioning, dual aggregate credit ceilings, RLS isolation, hierarchy-aware ledger/audit lineage, parent suspension, Founder-only cross-Distributor Agent reassignment, production Console UI, migrations, tests and documentation.

Not included: real multiplayer, cloud player-account synchronization, EGM4000 production telemetry, bespoke final art/audio for all titles, Android store/device release QA, or real-money functionality.
